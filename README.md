### What's here

**[trading-strategy-validation](https://github.com/moses-miertschin/trading-strategy-validation)** — A research project that asked whether a retail trading strategy can be *validated* by one person with free data. The answer was no, and establishing that carefully is the result. 548 automated checks, 121 registered perturbations that deliberately break the code to prove the checks can fail, a reproducibility sweep over 79 runnable scripts, and nine rounds of adversarial review. Nothing in it trades.

**[league-macro-coach](https://github.com/moses-miertschin/league-macro-coach)** — A 15-module League of Legends analytics system in Python. Pulls ranked match and timeline data from the Riot API, runs rule-based macro analysis, and generates item recommendations with evidence and confidence scoring. 42 test files. Deterministic by design: every recommendation traces to a named rule, and the optional AI layer only phrases findings it never computes.

**[text-reader](https://github.com/moses-miertschin/text-reader)** — A local text-to-speech desktop app. Paste text, adjust speed, hear it read. Python, tkinter, Piper. Fully offline.

**[auto-typer](https://github.com/moses-miertschin/auto-typer)** — A CLI tool that replays text as real keystrokes, with a versioned payload format, dry-run and verify modes, and a symbol torture-test suite built around the failure mode that actually matters for code.
